Google Sign-in Setup

One-time 5-minute setup (personal Google account, not work):

1
Go to console.cloud.google.com/apis/credentials
2
Create a new project, then enable YouTube Data API v3
3
Create an OAuth 2.0 Client ID (Web application type)
4
Add the URL of this page to Authorised JavaScript origins
5
Paste the Client ID above and click Save

Your Client ID is saved in your browser only. No server, no secrets needed.
